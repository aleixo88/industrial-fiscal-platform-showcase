# Current Product Status

This page separates product evidence from future validation. It is not a
certification statement.

## Status vocabulary

| Status | Meaning |
|---|---|
| Implemented | Capability exists in the private product codebase |
| Internally tested | Verified with controlled fixtures and automated tests |
| Operationally used | Exercised in a real industrial workflow |
| Ready for pilot configuration | Requires a real company and governed parameters |
| Externally homologated | Proven against the relevant external service |

These terms are not interchangeable.

## Commercial readiness boundary

The private product is positioned for controlled pilot configuration and
external validation. It is not represented here as universally configured,
nationwide tax coverage or externally homologated for an unidentified company.

Before a commercial go-live, the responsible parties must define the sold
scope, configure the actual issuer and integrations, govern applicable fiscal
coverage, execute external homologation and approve objective go-live criteria.
